# Archived plugins

These five plugins were de-listed from the marketplace on 2026-08-02. They were
verbatim copies of skills from Anthropic's Cowork skill bundle and community packs
(e.g. awesome-claude-skills) and carried **no ideas42-specific content**, so they
are no longer distributed as ideas42 plugins.

Nothing is deleted — every skill is preserved here and in git history. To revive one,
move it back under `plugins/` and re-add its entry to `.claude-plugin/marketplace.json`.
To get the same functionality with upstream updates, install the originals and
customize on install (see the main README, "What's not here").

Archived: deliverables (9), research-evidence (5), web-dev (6),
connector-automation (4), notion-workflows (4) — 28 skills total.
